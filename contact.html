Frequently Asked Questions

What is PhishShield?
PhishShield is a complete, static cybersecurity awareness and interactive learning web portal offering labs, quizzes, attack vector analysis, and career roadmaps.
Are the security labs scanning real external websites?
No. All interactive labs, password checkers, and URL risk analyzers run locally in client-side JavaScript as educational heuristic simulations.
Is user progress saved between sessions?
Yes! User XP points, earned rank badges, dark/light theme preferences, and quiz history are saved directly in your browser's LocalStorage.
Can I use PhishShield for a B.Tech major project or portfolio?
Absolutely! PhishShield was engineered specifically to showcase professional cybersecurity knowledge, glassmorphism UI/UX design, and complex client-side application logic.
