7.2 Banking Security

Common Financial Scams

  • UPI Collect Fraud: Scammers send 'Collect Money' requests misleading victims into entering PIN to receive funds.
  • QR Code Scam: Fake QR stickers at payment counters redirecting funds to fraud accounts.
  • ATM Skimming: Physical hardware overlays on ATM card slots stealing magnetic stripe data.
  • OTP Vishing: Fraud callers posing as bank managers urging victims to share SMS OTPs.

7.3 Cloud & AI Security

Cloud Service Models (SaaS / PaaS / IaaS)

In cloud security, responsibility is shared between vendor and customer depending on the service tier:

  • IaaS (AWS EC2 / Azure VMs): Customer manages OS, software patches, firewalls, and data.
  • PaaS (Heroku / AWS Elastic Beanstalk): Customer manages code & data; vendor manages OS & runtime.
  • SaaS (Google Workspace / M365): Vendor manages infrastructure; customer manages IAM user access.

AI-Powered Cyber Threats

  • AI Phishing: LLMs crafting hyper-realistic, grammar-perfect phishing emails personalized from social media OSINT.
  • Deepfake Video & Voice Cloning: Synthesizing CEO video calls to authorize fraudulent bank transfers.
  • AI Malware Mutation: Automated code refactoring to bypass traditional signature antivirus.
